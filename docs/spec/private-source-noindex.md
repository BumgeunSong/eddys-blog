# 비공개 모임 글 검색엔진 색인 제외 — 요구사항

> 기준 커밋: `ed05e79` (Add basic SEO: social share cards, sitemap, robots, metadata)

## 배경

'매일 글쓰기 프렌즈'(frontmatter `source: daily-writing-friends`, 157편)는 비공개
모임에서 쓴 글이다. 블로그에 아카이브로 남겨두는 것은 의도된 것이지만, 검색엔진을
통해 불특정 다수에게 노출되는 것은 원치 않는다.

직전 커밋에서 sitemap·robots.txt·OG 공유 카드·canonical이 도입되어, 이 글들이
검색엔진에 적극적으로 제출되는 상태가 되었다. 그 위에서 제외 규칙을 정의한다.

## 현황 (중요)

- 대상 글 157편은 **전부 2025년** 글이고, **2025년이 홈 연도**다.
  → 홈(`/`)에 나열되는 글이 사실상 이 글들뿐이다.
- 연도 페이지(`/{year}`)는 이미 `noindex, follow`다.
- 홈과 글 상세 페이지는 색인된다. sitemap은 홈 + 전체 글을 나열한다.

## 목표

대상 글의 **제목과 본문 어느 쪽도** 검색 결과에 나타나지 않는다. 단, 블로그에
방문한 사람은 지금처럼 찾아 읽을 수 있다.

## 비목표

- 로그인/인증 등 접근 제어 도입.
- 글을 `visibility: private`으로 전환 (그러면 사람도 못 읽는다).
- 대상이 아닌 글의 SEO 동작 변경.

## 기능 요구사항

| ID | 요구사항 |
|---|---|
| FR-1 | 대상 글의 상세 페이지가 검색엔진에 색인되지 않는다. |
| FR-2 | 대상 글의 이미지가 이미지 검색에 색인되지 않는다. |
| FR-3 | 이미 색인된 대상 글은 재크롤 이후 검색 결과에서 제거된다. 즉 크롤러가 제외 신호를 **실제로 읽을 수 있어야** 한다. |
| FR-4 | 대상 글은 sitemap에 포함되지 않는다. |
| FR-5 | 색인되는 목록 페이지(홈)에 대상 글의 제목이 나타나지 않는다. |
| FR-6 | 그럼에도 대상 글은 블로그 내에서 계속 도달·열람 가능하다 (색인되지 않는 연도 페이지 등을 통해). |
| FR-7 | 대상 글을 제외한 뒤에도 홈이 비어 보이지 않아야 한다. 홈은 '가장 최근 연도의 글 목록'에서 **'연도 무관, 대상 아닌 최근 N편'**으로 바뀐다 (현 규칙으로는 홈이 0편이 된다). |
| FR-7a | 홈이 더 이상 특정 연도를 대표하지 않으므로, 연도 내비게이션과 연도 페이지 생성 규칙이 이에 맞게 정리되어야 한다 (모든 연도가 `/{year}`로 접근 가능해야 한다). |
| FR-8 | 대상 글 페이지에 색인 제외 신호와 모순되는 메타데이터가 함께 나가지 않는다 (예: canonical). |
| FR-9 | 대상 글의 제목이 담긴 부수 산출물(OG 카드 이미지 엔드포인트 등)도 검색에 색인되지 않는다. |
| FR-10 | 링크를 메신저 등에 공유했을 때의 미리보기 카드는 유지된다. 검색 색인과 링크 공유는 별개로 취급한다. |
| FR-11 | 대상이 아닌 글 703편의 색인 동작은 변경되지 않는다. |
| FR-12 | 색인 제외 여부는 개별 글이 아니라 **소스 단위**로 지정한다. |
| FR-13 | 색인 제외 소스 목록은 한 곳에서 선언되고, 이를 필요로 하는 모든 지점(글 페이지·sitemap·홈 목록 등)이 그 선언 하나를 참조한다. |

## 제약

| ID | 제약 |
|---|---|
| C-1 | 콘텐츠 MDX 파일(860편)을 수정하지 않는다. FR-12를 만족하면 새 소스 추가 시에도 콘텐츠를 건드릴 일이 없다. |
| C-2 | URL 및 라우팅 구조를 변경하지 않는다. |
| C-3 | robots.txt로 대상 경로의 **크롤을 차단하지 않는다.** 접근을 막으면 크롤러가 제외 신호를 읽지 못해 FR-3이 깨지고, 기존 색인이 제목만 남은 채 영구히 유지된다. |
| C-4 | 기존 정적 생성(SSG) 빌드 파이프라인을 유지한다. |

## 수용 기준

| ID | 검증 |
|---|---|
| AC-1 | 빌드 산출물에서 대상 글 157편 **전부**가 색인 제외 신호를 갖는다. 누락 0건. |
| AC-2 | 대상이 아닌 글 703편 중 색인 제외 신호를 가진 것이 0건. |
| AC-3 | 생성된 sitemap에 대상 글 URL이 0건. |
| AC-4 | 생성된 홈 HTML에 대상 글의 제목 문자열이 0건. |
| AC-5 | 홈에 표시되는 글이 1편 이상이다. |
| AC-6 | 대상 글 페이지가 정상 렌더링되고, 블로그 내 탐색으로 도달 가능하다. |
| AC-7 | robots.txt가 대상 경로를 차단하지 않는다. |
| AC-8 | 타입체크와 프로덕션 빌드가 통과한다. |

## 결정 기록

- **홈 제목 노출**: 감수하지 않고 제외한다. (대안이던 '홈도 noindex'는 브랜드
  검색에서 대문이 사라지므로 기각)
- **홈 규칙 (FR-7)**: '연도 무관, 대상 아닌 최근 N편'. 대안이던 '홈 연도를
  2024년으로 내림'은 홈에 글이 2편뿐이라 기각.
- **N 값**: 30편으로 가정한다. 조정은 상수 하나로 가능해야 한다.

## 범위 밖 — 배포 후 수동 작업

- Search Console에서 대상 URL 접두어 삭제 요청. 코드만으로는 재크롤 시점까지
  검색 결과에 남는다.
